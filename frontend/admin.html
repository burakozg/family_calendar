Recipe editor
Add, import, and edit recipes (ingredients, steps, timing, provenance). To browse and search, use the Recipe Library under Meals.
Import recipes
Or import one recipe from a link (recipe site or Instagram) — or paste the full text. For Instagram, if the link doesn't work, paste the caption text instead.
Notion: open the recipes page → ••• → Export → format Markdown & CSV, Include subpages → drop the .zip above. Each page becomes a recipe — link-only pages are followed and read automatically. Recipes keep their original language; a page matching an existing recipe is queued under Pending imports to compare & merge instead of duplicating.
Data & backup
Download a zip snapshot for safekeeping or migration. To restore, unzip into the server's data/ directory (recipes land in data/recipes/) and restart the backend.

Meal planning
How the assistant plans the week. The weekly prompt drives the first draft; you refine it from the Meals page.
$ = cheaper, $$$$ = pricier. Recommended = a good balance of recipe-photo reading, meal planning and cost. Non-Claude models need their provider's key on the server (OPENAI_API_KEY, MISTRAL_API_KEY, or OPENROUTER_API_KEY — one key for the "(OpenRouter)" models).
The planner reads the saved plan history: it won't repeat anything from the last “avoid” weeks, and nudges back favourites not cooked in the last “variety” weeks.

Mail sync
Bi-directional sync with a mailbox.org alias: invitations emailed to the alias land on this calendar; local events are mirrored to the mailbox.org calendar and invitations are sent to the addresses below. Credentials are configured on the server (.env), not here.
